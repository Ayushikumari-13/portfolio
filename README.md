# 🌟 Ayushi Kumari - Developer Portfolio

A modern and responsive personal portfolio website built using **React.js** with a premium dark UI theme, smooth animations, glassmorphism effects, and fully responsive design.

# ✨ Features

✅ Modern Dark Premium UI  
✅ Purple + Cyan Gradient Theme  
✅ Fully Responsive Design  
✅ Glassmorphism Cards  
✅ Smooth Hover Animations  
✅ Active Navbar Highlight  
✅ Hero Section with Typewriter Effect  
✅ Projects Showcase  
✅ Certifications Section  
✅ Resume Download Button  
✅ Contact Form  
✅ Smooth Scroll Navigation  
✅ Mobile Friendly Layout  

---

# 🛠️ Tech Stack

- React.js
- JavaScript
- CSS3
- HTML5
- Vite
- React Simple Typewriter
